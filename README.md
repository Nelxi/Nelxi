### 👻 Привет, я Nelxi

Разрабатываю кроссплатформенные клиенты и исследую сетевые протоколы обхода DPI. Люблю, когда сложная сетевая штука выглядит просто и красиво: одна кнопка, живой интерфейс, ноль настроек, которые надо понимать.

Главный проект: **[Ghostly VPN](https://github.com/Nelxi/ghostly-vpn)** — открытый VPN-клиент и сервис **[ghostlynex.fun](https://ghostlynex.fun)**.
